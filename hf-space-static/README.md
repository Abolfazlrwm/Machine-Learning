# دستیار پرسش‌وپاسخ فارسی (RAG) — نسخهٔ مرورگری، بدون سرور

دموی زندهٔ ایدهٔ بازیابی ترکیبی پروژهٔ
[`rag-farsi-assistant`](https://github.com/Abolfazlrwm/Machine-Learning/tree/main/rag-farsi-assistant)
که **تمام استنتاج آن داخل مرورگر** اجرا می‌شود:

- **بازیابی معنایی** — بردارهای قطعه‌ها از قبل با `intfloat/multilingual-e5-small`
  محاسبه و در `embeddings.json` (۸۴ کیلوبایت) آمده‌اند؛ بردار *پرسش* در لحظه
  با [Transformers.js](https://huggingface.co/docs/transformers.js)
  و وزن‌های ONNX کوانتیزهٔ `Xenova/multilingual-e5-small` (~۱۲۰ مگابایت، فقط بار اول)
  در مرورگر ساخته می‌شود
- **بازیابی واژگانی** — امتیازدهی BM25-سبک (همان که در مخزن از صفر پیاده‌سازی شده)
  به‌عنوان مسیر جایگزین اگر دانلود مدل ممکن نشد
- **فیوژن RRF** (k=۶۰) — دقیقاً همان ایدهٔ هیبرید مخزن
- **پاسخ استخراجی همراه ارجاع** `[1] [2]` — فقط از متن منابع بازیابی‌شده

## چرا نسخهٔ استاتیک؟

Spaceهای Gradio/Docker در Hugging Face از تیر ۱۴۰۵ (ژوئیه ۲۰۲۶) به اشتراک PRO
نیاز دارند؛ Space استاتیک برای همه رایگان است. این نسخه همان معماری را
بدون هیچ سروری بازسازی می‌کند — و به همین دلیل هم «Edge/Client-side RAG»
است: هیچ پرسشی به هیچ سروری ارسال نمی‌شود.

## ساختار فایل‌ها

| فایل | نقش |
|---|---|
| `index.html` | رابط فارسی RTL (تم تیره، فونت وزیرمتن) |
| `app.js` | بارگذاری مدل، امتیازدهی، فیوژن و رندر |
| `retrieval.js` | هستهٔ مشترک بازیابی: BM25 + RRF + پاسخ استخراجی |
| `embeddings.json` | ۱۸ قطعه + بردارهای نرمال‌شدهٔ ۳۸۴بعدی |

## نسخهٔ کامل در مخزن

| قابلیت | این دمو | مخزن |
|---|---|---|
| بازیابی | E5-small + BM25 + RRF | **BM25 از صفر + RRF** + E5-base + MMR |
| رتبه‌بند مجدد | — | cross-encoder اختیاری |
| تولید پاسخ | استخراجی | Ollama / OpenAI با پرامپت فارسی سخت‌گیرانه |
| ارزیابی | — | مجموعه طلایی ۳۰ pair + سنجه‌های RAGAS-style (hybrid Hit@1 = 0.967) |
| سرویس‌دهی | مرورگر | **FastAPI + Docker** (`serving/`) |
